A program that writes one line, at most 160 characters, roasting the smart fridge:

> My smart fridge has a camera, Wi-Fi, and opinions — it just watched me eat cake at 2 a.m. and emailed my doctor about it.

The line is 121 characters: the fridge is no longer a dumb box, it is a snitch with a camera and a direct line to the doctor.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
